# Закрывающий тег

Адаптивная проектная работа для Яндекс Практикума о пройденных этапах обучения веб-разработке.

## О проекте

Страница состоит из восьми карточек с воспоминаниями об обучении. Для изображений используются разные CSS-фильтры, кнопки лайка сопровождаются анимацией SVG-сердца, а кнопка сохранения открывает модальное окно.

## Возможности

- адаптивная вёрстка от 320 пикселей;
- вариативный шрифт Inter;
- фиксированный фон из CSS-градиентов;
- CSS-фильтры для изображений;
- анимированные состояния кнопок и SVG-сердца;
- модальное окно на основе элемента `dialog`;
- ленивая загрузка изображений.

## Технологии

- HTML5;
- CSS3: Grid, Flexbox, переменные, фильтры, трансформации и анимации;
- JavaScript;
- SVG.

## Запуск локально

Проект не требует сборки или установки зависимостей. Клонируйте репозиторий и откройте `index.html` в браузере.
